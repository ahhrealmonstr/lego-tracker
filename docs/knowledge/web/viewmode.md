# ViewMode

The `ViewMode` type defines the primary navigation states for the web application's main view.

```typescript
type ViewMode = 'collection' | 'wishlist' | 'catalog'
```

## Values

- `'collection'`: Displays items the user already owns.
- `'wishlist'`: Displays items the user wants to acquire.
- `'catalog'`: Displays the full LEGO catalog for searching and adding new items.
